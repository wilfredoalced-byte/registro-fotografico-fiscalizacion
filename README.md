
# Registro Fotográfico de Fiscalización

## Descripción
Aplicación web desarrollada para registrar fiscalizaciones y organizar evidencias fotográficas, permitiendo generar un anexo fotográfico en formato Word.

## Objetivo
Facilitar el registro, almacenamiento y presentación ordenada de fotografías obtenidas durante una fiscalización.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Node.js y npm
- Vite
- IndexedDB
- Librerías para generar documentos Word

## Funcionalidades
- Registro de datos de fiscalización.
- Captura y carga de fotografías.
- Descripción de cada fotografía.
- Ordenamiento y eliminación de imágenes.
- Almacenamiento local mediante IndexedDB.
- Generación de anexos fotográficos en Word.
- Uso desde computadora y celular.

## Instalación y ejecución

1. Clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Instalar las dependencias:

```bash
npm install
```

4. Iniciar la aplicación:

```bash
npm run dev
```

5. Abrir la dirección local indicada por Vite.

## Estructura del proyecto

- `index.html`: estructura de la aplicación.
- `css/estilos.css`: estilos visuales.
- `js/app.js`: lógica principal.
- `package.json`: dependencias y scripts.
- `README.md`: documentación del proyecto.
